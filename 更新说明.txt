GitHub Desktop更新步骤
1. 解压本网站更新包。
2. GitHub Desktop选择transparent-video，菜单Repository → Show in Finder打开仓库。
3. 建议先把当前网站文件备份到仓库以外；不要改动隐藏的.git文件夹。
4. 将本包内index.html、assets、data、images、encoder、precomputed放入仓库根目录。
   index.html选择替换；文件夹选择合并并替换同名文件。不要将整个解压文件夹再套一层。
   仓库已有.nojekyll则保留。若需显示本包内的.nojekyll，可按Command + Shift + .显示隐藏文件。
   旧hash资源和旧pack留着不影响运行，新入口仅引用本次细亮边数据。
5. 回到GitHub Desktop，Summary填：更新细亮边确认版。
6. 点击Commit to main，然后Push origin。
7. 等待GitHub Pages部署完成，用原网站地址打开。若仍见旧效果，强制刷新或用无痕窗口。
